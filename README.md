# Лабораторная работа №1: Разработка веб-приложения на Python (Вариант 11)

Веб-приложение на базе фреймворка **FastAPI**, реализующее склейку двух изображений по горизонтали или вертикали с построением гистограмм распределения цветов.

## 📋 Описание задания (Вариант 11)

Веб-приложение должно:
- Склеивать две картинки в одну по вертикали или горизонтали (в зависимости от выбора пользователя).
- Выдавать графики распределения цветов исходных картинок и новой (склеенной) картинки.
- Быть развернутым на облачной PaaS-платформе.

## 🛠 Стек технологий

- **Python 3.12** — язык программирования.
- **FastAPI** — асинхронный веб-фреймворк для создания API и обработки форм.
- **Uvicorn** — ASGI-сервер для запуска приложения.
- **Jinja2** — шаблонизатор для генерации HTML-страниц.
- **Pillow (PIL)** — библиотека для обработки изображений.
- **NumPy** — библиотека для работы с многомерными массивами (используется для подготовки данных для гистограмм).
- **Matplotlib** — библиотека для построения графиков (гистограмм).
- **Pipenv** — инструмент для управления зависимостями и виртуальным окружением.
- **GitHub Actions** — система непрерывной интеграции (CI) для автоматического тестирования.
- **Render.com** — облачная PaaS-платформа для деплоя приложения.

## 🚀 Функционал приложения

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Приветственный эндпоинт ("Hello World"). |
| GET | `/some_url/{something}` | Возвращает HTML-страницу с переданным параметром. |
| GET | `/bimage` | Возвращает сгенерированное изображение в виде потока. |
| GET | `/image` | Отображает таблицу с двумя изображениями (статическим и динамическим). |
| GET | `/image_form` | Отображает форму для загрузки и обработки изображений. |
| POST | `/image_form` | Обрабатывает загруженные изображения и рисует на них эллипс. |
| **GET** | **`/stitch_form`** | **Отображает форму для склейки двух изображений (Вариант 11).** |
| **POST** | **`/stitch_form`** | **Обрабатывает форму, склеивает изображения и строит гистограммы.** |
